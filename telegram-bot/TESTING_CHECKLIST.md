# ✅ Чеклист ручного тестирования CRMino_bot

Проверить перед сдачей клиенту. Отмечайте пройденные пункты.

## 0. Подготовка
- [ ] Заполнен `.env` (`BOT_TOKEN`, `MANAGER_CHAT_ID`).
- [ ] Бот добавлен в группу менеджеров, `MANAGER_CHAT_ID` верный.
- [ ] (Опц.) Настроен Google Sheets, сервис-аккаунту выдан доступ к таблице.
- [ ] Бот запущен, в логах `Бот запущен (long polling)`, ошибок нет.

## 1. Старт и язык
- [ ] `/start` показывает выбор языка (RU/UA/EN).
- [ ] Выбор каждого языка меняет язык интерфейса (проверить все три).
- [ ] После выбора языка появляется главное меню с 4 кнопками.
- [ ] Кнопка «🌐 Сменить язык» снова открывает выбор языка.
- [ ] Повторный `/start` в середине воронки сбрасывает диалог в начало.

## 2. Главное меню и навигация
- [ ] `/menu` открывает главное меню из любого шага.
- [ ] На каждом шаге воронки есть кнопки (нет «тупиков» без действий).
- [ ] Кнопка «⬅️ Назад» возвращает на предыдущий шаг и НЕ теряет введённые данные.
- [ ] Кнопка «🏠 Меню» на любом шаге возвращает в меню.

## 3. Воронка лида (полный путь)
- [ ] «🛍 Оставить заявку» → вопрос о категории (6 кнопок).
- [ ] Выбор категории кнопкой ведёт к размеру.
- [ ] «🔎 Другое» просит ввести категорию текстом и принимает ввод.
- [ ] Размер: кнопки S–XXL, «Свой вариант» (ввод текста), «Пропустить» — все работают.
- [ ] Бюджет: варианты и «Пропустить» работают.
- [ ] Имя: принимает нормальное имя; отклоняет ссылки/цифры с подсказкой.
- [ ] Контакт: принимает `+380...` и email; отклоняет мусор с подсказкой и примером.
- [ ] Комментарий: можно ввести или «Пропустить».
- [ ] Экран подтверждения показывает ВСЕ собранные данные корректно.
- [ ] «✏️ Изменить» начинает воронку заново.
- [ ] «✅ Отправить» → появляется «печатает…», затем благодарность с временем ответа.

## 4. Передача менеджеру
- [ ] После отправки заявки в чат менеджеров приходит карточка со всеми полями.
- [ ] `/manager` из любого места отправляет карточку менеджеру.
- [ ] Карточка содержит шаг, на котором пользователь остановился (если воронка не завершена).
- [ ] Пользователю показывается ожидаемое время ответа.
- [ ] Кнопка «👤 Связаться с менеджером» в меню и на шагах работает.

## 5. Понимание пользователя (intent + эскалация)
- [ ] Текст «хочу оставить заявку» вне воронки запускает воронку.
- [ ] Текст «позовите менеджера» вызывает хендофф.
- [ ] Текст про доставку/оплату показывает FAQ.
- [ ] 3 непонятных сообщения подряд → бот предлагает менеджера (кнопкой).
- [ ] На шаге имени/контакта 3 неверных ввода подряд → предложение менеджера.

## 6. Надёжность и ошибки
- [ ] При выключенном Google Sheets заявка всё равно сохраняется (менеджер получает карточку).
- [ ] При включённом, но недоступном Sheets лид попадает в очередь и не теряется
      (проверить таблицу `pending_sync`; после восстановления — досинхронизация).
- [ ] Отправка стикера/фото/голосового не «роняет» бота — приходит вежливый ответ.
- [ ] Нажатие старой кнопки из прошлого сообщения не вызывает ошибок.
- [ ] В логах при недоступности CRM — предупреждения, а не падение обработчика.

## 7. Анти-спам
- [ ] Быстрое многократное нажатие одной кнопки не порождает дубли ответов.
- [ ] Бот не шлёт непрошеных «напоминаний».

## 8. Мультиязычность (выборочно)
- [ ] Пройти воронку целиком на украинском — все тексты локализованы.
- [ ] Пройти воронку целиком на английском — все тексты локализованы.
- [ ] Карточка менеджеру приходит на русском независимо от языка клиента.

## 9. Данные
- [ ] В БД (`leads`) появляется запись после каждой заявки со всеми полями.
- [ ] (Опц.) В Google-таблице появляется строка лида с корректными значениями.
- [ ] Язык клиента сохраняется и не переспрашивается при следующих сообщениях.
